# lan-send 支持

- 使用说明与下载：<https://github.com/TgolMsk/lan-send>
- 问题反馈：<https://github.com/TgolMsk/lan-send/issues>
- 常见问题
  - **找不到设备？** 确认两台设备在同一个 Wi‑Fi，并且对方打开了 lan-send 或 LocalSend；iOS 上首次使用需允许“本地网络”权限。也可以在“设备”页直接输入对方的 IP 地址。
  - **收到的文件在哪里？** 桌面端默认在“下载”文件夹（设置里可改）；iOS 上在“文件”App › 我的 iPhone › lan-send。
  - **剪贴板同步怎么开？** 先在“设备”页与对方配对（两端显示相同的 6 位校验码），之后自动同步（iOS 不支持剪贴板同步）。

# Support

- Documentation and downloads: <https://github.com/TgolMsk/lan-send>
- Report a problem: <https://github.com/TgolMsk/lan-send/issues>
- FAQ
  - **Devices not found?** Both devices must be on the same Wi‑Fi with lan-send or LocalSend open; on iOS allow the Local Network permission. You can also type the other device's IP address on the Devices page.
  - **Where are received files?** Desktop: the Downloads folder by default (changeable in Settings); iOS: Files app › On My iPhone › lan-send.
  - **Clipboard sync:** pair the devices first (both show the same 6-digit code); sync then runs automatically (not available on iOS).

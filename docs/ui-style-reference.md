# UI 视觉参考

来源：Dribbble「UI-UX, Website for Finance」（Arounda UI/UX，shot 27690776，2026-09-06 由用户指定）。
这是**视觉风格**参考，不是信息架构参考：它是金融网站着陆页，我们做的是传输工具，只借配色、材质、字形和节奏。
前端具体方案待用户提供 UI 设计后再定，本文用于让里程碑 5/6 的实现有一致的出发点。

## 作者给出的色板

| 角色（我们的推断） | 色值 |
|---|---|
| 最深背景 / 近黑 | `#050517` |
| 深靛蓝，主背景渐变的起点 | `#18185C` |
| 靛紫，主背景渐变的终点、图表线条 | `#4444A3` |
| 近白，浅色卡片与浅色模式底色 | `#FAFAFD` |
| 深灰蓝，浅色卡片上的正文 | `#3D434D` |
| 薰衣草灰，深色背景上的次级文字与刻度 | `#9FA1D4` |
| 薄荷绿，唯一的强调色（主按钮、涨幅、品牌图标） | `#1BEE79` |

## 观察到的风格要点

- **背景**：从左上近黑 `#050517` 到右下靛紫 `#4444A3` 的对角大渐变，面积大、过渡柔和，没有噪点或纹理。
- **层次**：深色底上叠两类卡片——半透明的"毛玻璃"深色卡片（低不透明度白色填充、细的高光描边）和纯白 `#FAFAFD` 的实心卡片；白卡用来承载最重要的数字。卡片圆角大（约 16–24 px），阴影非常柔和且偏长。
- **文字**：几何无衬线（近似 Inter / Manrope 一类），标题超大、字重中等（不是粗体）、字距略收、行高紧；数字用同一字体，尺寸分级明显（标题 > 关键数字 > 标签）。标签是小号、低对比的薰衣草灰。
- **强调**：整张图只有一个强调色（薄荷绿），用在主按钮"Open an account"、正向变化 `+25,42%` 和品牌立方体图标上；按钮是全圆角胶囊、深色文字。
- **数据可视化**：单色折线（靛紫到亮蓝），线条较粗、平滑曲线，当前点用实心圆点标注，时间范围切换（1D/1W/1M/…）是无边框文字按钮。
- **头像与人物**：小圆形头像堆叠，用于"参与者"类信息。
- **动效暗示**：轻微透视与倾斜只是展示手法，产品内不需要。

## 对本项目的映射（供前端实现时参考，待 UI 方案确认）

- 深色为主视觉，同时提供浅色模式：浅色以 `#FAFAFD` 为底、`#3D434D` 为正文、`#4444A3` 为主色。
- 设备列表 = 半透明深色卡片；当前传输 / 剪贴板最近一条 = 白色实心卡片突出。
- 进度与速度曲线沿用单色折线风格；成功状态用薄荷绿，失败状态需要另定一个红色（参考图中没有）。
- 主操作按钮（发送、配对）用薄荷绿胶囊；次级操作用描边或文字按钮。
- 圆角 16–24 px、阴影柔和、间距宽松；避免多种强调色并存。
- 三端一致：iOS 上同一套配色与卡片，但触控目标 ≥ 44 pt，导航改为底部标签栏。

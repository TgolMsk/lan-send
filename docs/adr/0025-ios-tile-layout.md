# 0025. iPhone 界面改为“磁贴”布局

- 状态：已接受
- 日期：2026-10-18

## 背景

ADR-0024 换了颜色、字体和材质，但 iPhone 上仍是桌面卡片排成一列：每张设备卡带四五个按钮，发送要经过“卡片 → 发送弹窗 → 选文件 → 开始发送”，设置页是一堆表单加“保存”按钮，收到请求是居中弹窗。2026-10-18 出了四套 iPhone 布局（清单、附近、磁贴、会话），用户选了“磁贴”：像控制中心，一台设备一块。

## 决策

- **适用范围**：交互按 `platform.mobile`（iOS，含 iPad）切换，排版按宽度（窄屏两列，宽屏自动多列）。桌面版和窄桌面窗口不变。
- **设备页**：大标题，右上角玻璃圆按钮（搜索、刷新）；进行中的传输是一块置顶宽磁贴，点按进传输页；设备是两列方磁贴（类型色圆标、在线绿点、收藏星、已配对链标），末尾一块虚线磁贴“按地址发送”。
- **点按磁贴**：展开设备卡片，两块大按钮“发送照片与视频”“发送文件”，选完立即发送，不再经过发送弹窗；下面一排圆形开关：收藏、配对 / 解除配对、重命名、忘记；底部是指纹和端口。不在线的设备不能发送、不能配对。
- **传输页**：当前传输是一块大磁贴（进度环、速度、剩余时间、取消），文件按三列缩略图排列；其他传输是两列小磁贴，带取消或移除。
- **收到请求**：从屏幕顶部（灵动岛位置）展开的黑色横幅，写明来源、文件数和大小、前三个文件，按钮是拒绝 / 接收。
- **设置页**：iOS 分组列表，改动立即保存（桌面仍有“保存”按钮）；选项用系统选择器，数字和文字在行内编辑。
- **其余弹窗**（配对、PIN、重命名、确认、按地址发送）在 iPhone 上贴底浮起。
- **配色**：iOS 单独一组底色，浅色 `#F2F2F7`、深色纯黑加 `#1C1C1E` 表面，与系统分组列表一致；仍在 `tokens.css` 里。
- **不做**：长按菜单、磁贴排序、桌面小组件和实时活动（需要原生扩展）。

## 备选方案

- 清单（像“设置”）：最稳，但和现状差别小。
- 附近（雷达）：设备一多就排不下。
- 会话（像“信息”，每台设备一串记录）：要把历史按设备整理，改动最大。

## 后果

- 正面：发送少一步；设置不用找“保存”；收件提示不挡住当前页面。
- 负面：一屏约放六台设备，多了要滚动；手机和桌面的设备页、设置页各有一套组件。

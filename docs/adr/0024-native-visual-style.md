# 0024. 界面与图标改为“原生”视觉风格

- 状态：已接受
- 日期：2026-10-18

## 背景

里程碑 6 的界面照一张金融网站参考图做：深靛蓝对角渐变、半透明卡片、薄荷绿强调色（原 `docs/ui-style-reference.md`），图标是衬线 L 加纸飞机的生成图。用户要求整体换掉。2026-10-18 出了四套方案（纸本、器物、原生、色块，各含图标、色彩字体、深浅两色的关键页面），用户选定“原生”：尽量像 macOS 26 / iOS 26 自带的工具。

## 决策

- **字体**：只用系统字体（苹果平台 SF Pro + 苹方，Windows Segoe UI Variable + 微软雅黑），不打包字体文件。
- **色彩**：中性灰窗口底、白色（深色为 `#222225`）表面；强调色系统蓝，开关与“在线”用系统绿，危险操作用系统红。颜色全部是 `tokens.css` 里的变量，浅色、深色各一组；组件样式只引用变量。
- **布局与材质**：桌面侧栏是悬浮在窗口里的圆角半透明面板（红绿灯落在面板内）；iPhone 底部标签栏是悬浮胶囊。半透明用 CSS `backdrop-filter` 模拟，不开窗口透明：Tauri 在 macOS 上做透明窗口要启用 `macos-private-api`，Mac App Store 不收。
- **控件**：按钮、搜索框、标签栏为胶囊形；卡片 16 px 圆角加极淡阴影，不用描边。桌面设备页是大图标卡片（按设备类型着色：手机蓝、电脑石墨、其它青色），手机上是列表，所有操作保留。
- **图标**：蓝色渐变底，白色“手机把文件跳到显示器”的图形。源文件是 `docs/brand/icon.svg`，`apps/app/scripts/make-icons.mjs` 用本机 Chrome 渲染出 iOS（满版、无透明）、macOS（824 px 圆角矩形加阴影的模板）和侧栏小图，再交给 `cargo tauri icon`。macOS 菜单栏改用单色模板图标（`icons/tray-template.png`），随系统深浅色反色；Windows 托盘仍用彩色图标。
- **不做**：真正的窗口毛玻璃材质；Liquid Glass 的分层图标（Icon Composer `.icon`）；官网 `lansend_web` 的改版（另行决定）。

## 备选方案

- 纸本（编辑排版）、器物（硬件质感）、色块（每台设备一种颜色）：辨识度更高，但需要打包字体、维护成本更高，用户未选。
- 开 `macOSPrivateApi` 用 `NSVisualEffectView` 做真材质：观感最好，但上不了 Mac App Store。

## 后果

- 正面：和系统观感一致，深浅色都完整；不再打包字体；颜色集中在一个文件，以后换强调色只改变量。
- 负面：辨识度比其它三套低；Windows 上会带一点 Mac 的味道；`backdrop-filter` 在侧栏和标签栏上有少量合成开销。
